# Employee Attrition Prediction Using Machine Learning

## Objective
Predict whether an employee is likely to leave the company based on job satisfaction, salary, performance, and work-life factors.

## Suggested workflow
- Load and clean employee dataset
- Encode categorical values such as department and role
- Train machine learning models for classification
- Evaluate using accuracy, precision, recall, F1-score, and ROC-AUC

## Models to try
- LogisticRegression
- RandomForestClassifier
- GradientBoostingClassifier
- XGBoost
