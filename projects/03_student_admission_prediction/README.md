# Student Admission Prediction Using Machine Learning

## Objective
Predict whether a student will be admitted based on academic and personal features.

## Common models
- LogisticRegression
- DecisionTreeClassifier
- RandomForestClassifier
- Support Vector Machine

## Evaluation metrics
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
