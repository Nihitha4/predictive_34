# Loan Approval Prediction Using Classification Algorithms

## Objective
Predict whether a loan application should be approved based on applicant information and financial history.

## Suggested workflow
- Explore applicant features and missing values
- Encode categorical variables
- Train classification models
- Evaluate with accuracy, precision, recall, F1-score, and ROC-AUC

## Models to try
- LogisticRegression
- RandomForestClassifier
- XGBoost
- GradientBoostingClassifier
