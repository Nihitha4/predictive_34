# Credit Card Fraud Detection using Machine Learning

## Objective
Identify fraudulent card transactions from highly imbalanced transaction data.

## Key considerations
- Handle class imbalance
- Use stratified train/test splits
- Evaluate with precision-recall metrics
- Consider SMOTE or class weights

## Suggested models
- LogisticRegression
- RandomForestClassifier
- XGBoost
- IsolationForest or anomaly detection approach for experimentation
