# Customer Purchase Prediction Using Classification Models

## Objective
Predict whether a customer is likely to make a purchase based on demographic and behavioral features.

## Suggested workflow
- Preprocess categorical and numerical features
- Train multiple classifiers
- Use accuracy, precision, recall, F1-score, and ROC-AUC for evaluation
- Compare outcomes across models

## Models to try
- LogisticRegression
- RandomForestClassifier
- GradientBoostingClassifier
- XGBoost
