# Customer Churn Prediction

## Objective
Predict whether a customer is likely to leave a service or product.

## Suggested workflow
- Analyze customer demographics and service usage
- Encode categorical features
- Train a classification model
- Compare model outputs using confusion matrix and ROC-AUC

## Models to try
- LogisticRegression
- RandomForestClassifier
- GradientBoostingClassifier
- XGBoost
