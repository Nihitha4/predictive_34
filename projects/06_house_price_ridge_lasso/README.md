# House Price Prediction Using Ridge and Lasso Regression

## Objective
Build a regression model for price prediction and compare Ridge and Lasso regularization.

## Concepts covered
- Linear regression basics
- Feature scaling
- Regularization
- Model selection and evaluation

## Suggested workflow
- Explore data and detect missing values
- Standardize features
- Train Ridge and Lasso models
- Tune alpha values
- Compare using RMSE and R2 score
