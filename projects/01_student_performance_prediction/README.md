# Student Performance Prediction Using Model Tuning

## Objective
Predict student performance using educational features and compare models after tuning hyperparameters.

## Suggested workflow
- Load the dataset
- Clean and preprocess features
- Train multiple models such as RandomForest, GradientBoosting, or XGBoost if available
- Tune hyperparameters using GridSearchCV or RandomizedSearchCV
- Evaluate with MAE, RMSE, or accuracy depending on the target
