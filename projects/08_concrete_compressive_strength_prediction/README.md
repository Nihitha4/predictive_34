# Concrete Compressive Strength Prediction Using Regression

## Objective
Predict the compressive strength of concrete based on its ingredients and mix characteristics.

## Suggested workflow
- Load the concrete dataset
- Explore feature relationships and missing values
- Split data into train and test sets
- Train regression models such as RandomForestRegressor or GradientBoostingRegressor
- Evaluate using MAE, RMSE, and R2 score
