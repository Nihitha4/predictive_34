# Car Price Prediction Using Regression Models

## Objective
Predict the price of a car using vehicle specifications, mileage, condition, and other features.

## Suggested workflow
- Clean and encode categorical values
- Explore correlations between price and features
- Train regression models such as LinearRegression, RandomForest, or GradientBoosting
- Compare performance using RMSE and R2
