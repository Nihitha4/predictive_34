# Heart Disease Prediction Using Classification Models

## Objective
Predict the likelihood of heart disease using clinical and lifestyle indicators.

## Suggested workflow
- Load the health dataset
- Handle missing values and encode categorical features
- Train classification models
- Compare using accuracy, ROC-AUC, and confusion matrix

## Models to try
- LogisticRegression
- RandomForestClassifier
- GradientBoostingClassifier
- SVM
